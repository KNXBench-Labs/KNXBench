## Hierarchy move slices — model and tests

`BuildingPart` and `GroupRange` are flat per-installation lists with *both* a parent ID and an ordered parent `children` list. Forward moves change both references only after validating the source's unique current placement, unique target, and absence of cycles; failed commands leave the model and undo stack unchanged. Normal moves append to the target; `RestoreBuildingPartPlacement`/`RestoreGroupRangePlacement` retain the original child index for exact undo/redo and atomic batch rollback. A RED regression discovered that normal cycle checks also blocked undoing a successful repair of an *already imported* building cycle. Internal restore now bypasses forward-only cycle and, for ranges, destination-span validation, while retaining structural identity and insertion-position checks. Thus imported invalid originals remain recoverable; this does not permit new invalid user moves.

For ranges, forward moves additionally reuse `validation.rs` containment and sibling-overlap checks, and leave address spans and group-address references unchanged. REST clients must send `parentId` explicitly: numeric parent or JSON `null` for root. Omitting it returns HTTP 400 rather than accidentally moving to root. The Properties pickers exclude self/descendants, refuse ambiguous projected identities, retain the previous selection on server errors, and gate later installations. They are accessible native `<select>` controls, but authoritative range/address validation stays in Core. Store incremental sync remains a documented no-op for these structure commands; native whole-project save/reopen is the durability mechanism.

Evidence: building Core RED E0599 → 19 filtered Core building tests GREEN; HTTP RED 404 → 1 GREEN; four Inspector RED cases → 34 GREEN, and an additional ambiguous-placement test. A separate RED undo test failed on `BuildingPartCycle` before the restore fix and passed afterwards. Group range Core RED E0599 → 18 filtered range tests GREEN; HTTP RED 404 → 1 GREEN; five Inspector RED cases → 39 GREEN after updating the old restricted-action expectation.
