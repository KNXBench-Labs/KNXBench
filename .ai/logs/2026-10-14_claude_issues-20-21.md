# 2026-10-14 — Claude: issues #20 and #21

## #21 — a reopened `.knxdb` lost its application programs

**Cause.** Since `f12ec0e8` an import with a product database installs the
`M-*` manufacturer files only into `~/.local/share/knx/products.sqlite`; the
`.knxdb` kept just the manifest (`manufacturer_ref`: path, SHA-256, length,
kind). The Docker image set `KNX_DATA_DIR=/data` but the product database
followed `$HOME`, so a rebuild (or another computer) left `resolve_program`
with nothing to resolve: "no application program can be resolved".

**Owner decision (clarify): full fix.**

- Store schema 15 → 16: table `manufacturer_file` (sha256 PK with a hex/length
  CHECK, source_path, len, codec `zlib`, bytes). Own table, not the snapshot
  and not the history: undo/redo/versions never copy megabytes of XML; history
  images with rows are refused, the semantic hash skips the table.
- `knx_app::manufacturer_files`: `embed_into` (after Save/Save As/download;
  bytes from the product DB, else from the earlier file), `reinstall_from_file`
  (after open), `restore_from_knxproj` (outer members only via
  `Container::open_outer`, hash-matched, project untouched).
- Server: `ParameterPanelDto.unresolvedProgram`, route
  `POST /api/project/manufacturer-files/restore` (login-guarded, session log).
- Web: `UnresolvedProgramNotice` (EN/DE "du"), keeps its summary across the
  panel reload.
- CLI `knx import --store` embeds too. Docker: `XDG_DATA_HOME=/data/.knxbench-share`.
- Selective import model 15 → 16 (re-audited, no Project field added).
- ADR-0128, KL-183, LEDGER row and count line, DATA_MODEL, IMPORT_EXPORT,
  manual 05/11, research note (M-* members are never encrypted in real
  protected exports: verified on three xknxproject exports).

**Evidence beyond tests.** Temporary probe: two real ZipCrypto exports restored
without password (4/4, 2/2 devices), largest private project 76/76 devices,
248 files, 18 MiB carried (185.8 MiB raw).

**Pitfalls met.** Literal `PRAGMA user_version == 15` asserts in
`crates/knx-store/tests/{functions,notes_admission}.rs` → use
`knx_store::CURRENT_SCHEMA_VERSION`; six predecessor fixtures need
`DROP TABLE manufacturer_file;`; `knx-desktop` needs `npm run build` before the
workspace test; LEDGER section count lines must follow a new row.
