# ADR-0132: Offline source images do not grant device download admission

Status: accepted for the bounded source implementation; field support unchanged.
Date: 2026-10-15.

## Context

The owner authorised maximal evidence-backed device-free implementation, with
physical validation later in the field. Existing070nh hardware evidence cannot
establish another family's table widths, indexed sending semantics, parameter
encoding or recovery. Original Resources distinguish three-byte legacy objects
and ASAP-indexed association rows from Easy3's four-byte descriptors and sorting.
The retained product template is intended to be modified with parameters; its
bytes need not be identical to every declared default (Cookbook Load Controls p7).

## Decision

Keep `build_download_image` and all public programming admission unchanged.
Add a separate `build_system2_image` library entry using the same actual product
parameter/Dynamic resolver with an explicit private layout discriminator. Put
System2-specific evidence/bounds checks in a focused private module, not UI or a
second parameter engine. Core owns the exact standalone association byte grammar.

Require the existing source-bound metadata witness and always disclose a named
offline-image inference. No output claims a complete executable procedure,
firmware acceptance, backup completeness or Verified status. The existing memory
planner continues to reject System2 output. No schema/dependency change.

A directly placed numeric octet is deterministic without endian assumptions;
its source template may differ from the configured value. For inferred forms,
require explicit source-default corroboration and reject ambiguous edited
multi-byte numbers. Source contradictions are named research boundaries, not
reasons to switch endian order, choose another union member or relax recovery.
Whole-source assembly may therefore refuse while independently proven codecs
and synthetic end-to-end source assembly are usable.

## Consequences

The same evaluator handles supported types once, while profile-specific table
and placement rules cannot leak into existing070nh behaviour. Negative tests must
pin overflow, table/parameter overlap, source masks, defaults, unsupported flags
and unchanged admission. A real fixture's unresolved16-bit source/default case
remains a refusal, not hardware support. Actual property/memory planning, whole
mutation recovery and field validation require their own completed contracts.

See [source-image contract](../contracts/offline-download-system2-image.md) and
[overall scope](../contracts/offline-download-expansion.md).


## System-1 application (16 October 2026)

Apply the same offline/execution separation to a bounded0012/DefaultProcedure
entry. Reuse the evaluator and existing Core Type-1/indexed-association codecs;
share only proven source validation via an explicit private family argument.
Read and protect retained pointer bytes. Direct FixupList declarations refuse
until independently interpreted; do not count omitted-fixup images as successful.
The extra source-view boolean is nonpersisted; no schema or public admission
change. [System-1 contract](../contracts/offline-download-system1-image.md).


## Shared source transformation refusal (16 October 2026)

Retained transformation declarations must gate every consumer of the parsed
source subset, not just the newest image entry. P6 centralizes direct FixupList
refusal before the existing shared image assembler; exact System-1 diagnostics
are retained, Easy3/System-2 omission regressions fail before the correction.
Do not infer a general no-op exemption from matching source/master words.
[Integrity contract](../contracts/source-fixup-integrity.md).

## Exact UP258 continuation (16 October 2026)

Retain the same boundary for the [fresh exact-source audit](../research/2026-10-16-up258-vertical-path-audit.md):
characterization of every source declaration/configured first refusal is not
a full image or executable plan. Do not waive LegacyPatchAlways based on
invisibility/default bytes or manufacture a recovery certificate from memory
plus load-status reads. Keep production admission closed until the defining
source/translation/reconstruction contracts are independently evidenced.
This continuation adds no layer, second evaluator, schema or physical transport.
