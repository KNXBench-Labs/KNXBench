## Rules every package follows

These rules belong to every package file; a package file may tighten them, never
loosen them.

1. **Start.** `git fetch`, then read the top entries of `origin/main`'s
   `.ai/CURRENT_STATE.md` (`git show origin/main:.ai/CURRENT_STATE.md | head -c 18000`;
   the root checkout's copy is stale). Check `git worktree list` and running
   gates (`ps -eo pid,etime,args | grep -E 'run_web_gate|cargo|playwright'`).
   Confirm on fresh `main` that the package's gap still exists; if another
   session delivered it, stop and report.
2. **Claim.** Push a one-line claim entry to the handover on `main` before the
   first code change, and grep worktrees and commit subjects for the same scope.
3. **Workspace.** A fresh worktree off `origin/main`
   (`<sources>/KNXBench-<topic>-<date>`), never the root checkout. Never merge,
   rebase onto or push a branch from before the KL-185 history rewrite; use its
   copy under `refs/kl185-rewritten/heads/<branch>`.
4. **Method.** Tests first (a RED observed before the fix), smallest clean
   change, no unrelated refactors, no new dependencies without an ADR.
   KNX Core stays free of UI, server and storage concerns.
5. **Gate.** `cargo fmt --check`, workspace Clippy `-D warnings`, owning crate
   tests, `cargo run -p xtask -- check-ledger`, `check-anchors`,
   `check-headers`, `check-layering`, `python3 tools/check_documentation.py`
   (includes the local-details guard of ADR-0135), and
   `tools/run_web_gate.py --profile web` when `apps/knx-web` changes. Product
   database or import changes also run the private corpus
   (`tools/run_corpus_tests.py`, root-only corpus; see DEVELOPER_PITFALLS).
   Until P4 lands, run Rust tests with a resolved (non-symlinked) `TMPDIR`.
6. **Documentation.** Update the package's contract, ADR (new decisions only),
   `docs/IMPLEMENTATION_STATUS.md`, the KL dossier and catalogue summary, the
   ledger row (counts regenerated by script, never by hand), `docs/OPEN_WORK.md`,
   the user manual where users see the change, the handover and a log in
   `.ai/logs/`. Placeholders instead of local paths, host or system details.
7. **Delivery.** Commit as `KNXBench <github@knxbench.com>`, no `Co-Authored-By`,
   a concise message with a little humour. Push to `main` after the gate is
   green; if `main` moved, re-merge with `main` as first parent and re-gate per
   the moving-main rules, then read back local = tracking = `ls-remote`.
8. **Not authorised by any package:** releases, tags, deployments, container
   restarts, bus or device access, contact with manufacturers or the KNX
   Association, subagents, external coding CLIs.
9. **End.** Retire the package's own worktree, branch and scratch after the
   readback, write the final handover entry, and stop. A package never starts
   the next one by itself.
