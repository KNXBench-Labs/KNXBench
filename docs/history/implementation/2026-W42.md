almost all one `import:unsupported` line per retained manufacturer file. The session

  status counts and a reopened project's historical counts

  wording classifier `retained_payload_label` sits next to the code that writes it.

  evidence) plus refusals; historical recount equals the fresh rule; text-less rows

<a id="2026-10-13--issue-7-the-appimage-may-save-its-own-logs-again"></a>
## 2026-10-13 — Issue #7: the AppImage may save its own logs again

GitHub issue #7, reported by hagbardZ after a successful ETS 5.7 import on
`v0.1.0-alpha.10`: *Export log (JSON)…* failed with `Command save_session_log not allowed by
ACL` (KL-181).

- **Cause.** A release window loads the UI from `http://127.0.0.1:<port>`, a remote
  origin to Tauri; remote origins reach app commands only through a granted
  permission, and none existed for the shell's own commands. The bus monitor's
  capture export failed the same way. Every AppImage since alpha.5 is affected; web and
  Docker download the file in the browser and are not.
- **Fix** (`7ba0989e`). `permissions/app-commands.toml` declares
  `allow-save-session-log` and `allow-save-bus-monitor-capture`;
  `capabilities/default.json` grants them to the main window only. The two commands
  are generic over the runtime and registered from one `app_command_handler!` list.
- **Tests.** `app_command_acl_tests` (2) builds the mock runtime with the real
  capabilities: from the release and the debug origin the main window reaches both
  commands (they fail only on the missing argument); the diagnostics and a Flow
  window are refused. Red before the fix on the report's refusal branch, red again
  with the grants removed. Desktop tests 14/0, Clippy `-D warnings`, fmt.
- **Boundary.** Mock runtime, not a native WebKitGTK window; the save dialog was not
  opened. Users get the fix with the next AppImage. The 2840 warnings in the report
  are mostly one `import:unsupported` line per retained manufacturer file; grouping
  them is a separate follow-up.

## 2026-10-12 — AppImage no longer ships libwayland-client (issue #6)

The alpha.9 AppImage aborted on Kubuntu 24.04 with `Could not create default EGL
display: EGL_BAD_PARAMETER`. Root cause: the bundled `libwayland-client` from the
