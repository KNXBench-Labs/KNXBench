## Scope submitted for approval

1. User fixes: retained manufacturer files on native save/reopen, desktop
   export destinations, verified text fills, contextual creation, trees, log
   and navigation/loading repairs.
2. Highlights: pending-programming marks, bounded read-only project/device
   comparison, universal support report, revision-bound edits, Functions and
   previewed batch naming.
3. Upgrade: independent backups first; native/model14→16 and product22→23.
   Older applications refuse upgraded native files. Docker port remains8484;
   publishing an image does not replace the running container.
4. Explicit limits: no new physical-device acceptance, broad ETS compatibility,
   ETS export, KNX Secure, individual-address programming, WebKitGTK/Orca feature
   acceptance or unlocking of System-2/MV-0025/little-endian programming.
5. Distribution/front door: Linux AppImage/MCP, multi-architecture Docker,
   refreshed bilingual website/README stills and manual. Established tone,
   approved Evolution Story and historical recordings remain intact.

Repository visibility is public. Fresh fetch showed no main commits outside
the frozen candidate. Alpha12 tag and release were absent at inspection.
Owner Go is reserved before tag/release/upload, Docker version/latest publication
and website cutover. Public-download checksums, registry revision/digests and
