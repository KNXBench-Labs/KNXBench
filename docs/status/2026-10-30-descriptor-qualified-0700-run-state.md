## Compatibility and residual requirements

New matching exact-0700 records add optional, non-null `runStateMask: "0700"` from
actual matched identity, including failures before description. New description
vocabulary requires it; `unsupportedDatatype` alone requires integer PDT 1..63.
Raw descriptor/access/response-index/error strings do not enter the shared
record. Actual 0701/0705 producers omit the marker byte-for-byte; legacy records
remain readable without inference or rewriting. **Older strict readers may
refuse new 0700 records**; no seamless downgrade or forward-read promise follows.
