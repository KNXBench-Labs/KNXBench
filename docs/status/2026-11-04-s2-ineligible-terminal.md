version is bound to the genuine admission and the known simulator seed; the
injected zero payload differs from it. The current live observation producer
stores only version deviations, and recovery serialization/progress derive the
same difference-only representation. Here None means a matching read, not a
retained raw byte array. An early zero response would become a deviation and
fail the phase oracle. This inference is restricted to the inspected current
live producers and real worker association; it is not a legacy missing-evidence
or reconstructed-raw-byte claim.
