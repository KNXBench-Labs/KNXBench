## Contract and implementation

The [primary observation and admitted contract](../research/2026-11-05-saved-schema20-node-text.md)
permit literal saved `Node/@Text` only for an owning project at schema 20 and
an explicit project/20 tree or its wholly inherited fragment. The existing
retained-source ownership/hash/structure checks remain authoritative. A separate
identity-only path keeps captions out of duplicate/prefix checks and opaque keys.

Optional `ProjectTreeNode.text` preserves raw XML-normalized empty/whitespace
values; absent legacy JSON remains valid and absent text is not serialized.
Above 4,096 UTF-8 bytes only display text is withheld, without truncating or
rewriting the retained original. Plain React text accompanies IDs; blank values
fall back to IDs, the saved ID path stays visible, and search includes admitted
Folder text without promoting refused or Channel-only placements. There is no
manufacturer lookup, translation, HTML/template evaluation, module authority,
current-placement reconstruction or domain/storage/command/protocol change.
